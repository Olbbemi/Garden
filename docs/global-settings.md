# 전역 설정 관리 기준

Garden은 공용 지침과 Codex 및 Claude 전역 설정, 에이전트 훅의 원본과 기준을 관리한다.
Git 공통 훅의 설치, 연결과 갱신은 Hortulanus가 담당한다.
스킬과 플러그인의 개발 원본은 해당 프로젝트에 두며 사용자 범위에 설치됐다는 이유로 Garden으로 옮기지 않는다.

## 관리 원칙

- 공통 내용, 계정별 및 장비별 값, 도구가 갱신하는 실행 상태를 구분하여 파일 전체와 개별 항목 중 관리 범위를 정한다.
  후보 목록 자체는 설치나 링크 전환의 승인이 아니다.
- 실제 도구의 탐색과 저장 동작을 확인하여 배치 방식을 정한다.
  스킬과 플러그인의 설치 및 활성화 설정은 개발 원본과 구분하며, 캐시를 공용 원본으로 쓰거나 설치 구조를 중복하지 않는다.
- `AGENTS.override.md`는 임시 대체용으로 상시 링크에서 제외한다.
- `~/.claude.json`은 인증과 실행 상태 등이 섞여 있으므로 파일 전체를 연결하지 않고 필요한 MCP 등록만 검토한다.

## 현재 적용 상태와 후보

| 도구 | 대상 | 상태 |
| --- | --- | --- |
| Codex | `~/.codex/AGENTS.md` | `global/AGENTS.md` 원본으로 연결하고 clone 및 충돌 회귀 검증 완료. 새 세션과 IDE에서의 지침 인식은 미확인. |
| Codex | `~/.codex/config.toml` | 모델, 권한, MCP, 훅 등의 공통 설정 후보. |
| Codex | `~/.codex/rules/`, `~/.codex/agents/`, `~/.agents/skills/` | 실행 정책, 에이전트 설정과 사용자 스킬 배치 후보. |
| Codex | `~/.codex/hooks.json`, `config.toml`의 훅 정의 및 실행 스크립트 | 이벤트와 동작을 확정한 뒤 검토할 후보. |
| Claude | `~/.claude/CLAUDE.md`, `~/.claude/settings.json` 및 훅 스크립트 | 원본과 배치 방식 미확정, 적용 보류. |
| Claude | `~/.claude/` 아래 `rules/`, `agents/`, `skills/`, `output-styles/` | 필요성과 동작을 개별 검토하며 적용 보류. |
| Claude | `~/.claude/commands/` | 기존 명령이 필요한 경우 스킬 통합 가능성과 함께 검토. |
| Claude | `~/.claude.json`의 MCP 설정 | 전체 파일 링크 제외, 별도 등록 방식 미확정. |

경로는 기본값이다.
적용 전 현재 버전의 공식 문서와 사용자 환경을 확인한다.
보류는 사용자 환경에 파일이나 링크가 없다는 뜻이 아니며, 후보의 저장 및 갱신 동작은 미검증이다.

Codex의 `hooks.json`과 `config.toml` 인라인 훅은 같은 계층에서 병합되므로 한 방식을 선택해 중복 실행을 피한다.
형식 지원과 링크 배치의 안정성은 별도로 검증한다.
참고: [Codex 훅](https://learn.chatgpt.com/docs/hooks),
[Claude 설정 디렉터리](https://code.claude.com/docs/en/claude-directory).

## 대상별 검증 기준

- CLI 및 IDE 새 세션의 실제 인식, 원본 변경 반영 시점과 재시작 필요 여부.
- 파일 및 디렉터리 링크별 탐색과 쓰기, 도구의 저장과 항목 추가, 업데이트 후 링크 유지.
- 훅의 실행 권한, 인자, 경로 해석과 작업 디렉터리에 무관한 실행.
- 충돌 시 원본 보존, 해제와 복구 가능 여부.

결과는 `미검증`, `관리 대상으로 유지`, `관리 대상에서 제외`, `대체 배치 방식 필요`로
구분하고 적용 여부와 확인한 환경 및 범위를 기록한다.
부분 검증을 전체 완료로 표시하거나 확인하지 않은 버전의 동작을 보장하지 않는다.
